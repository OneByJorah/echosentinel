# Changelog

## 1.0.0 (2026-11-02)

First release.

* Four-slot (configurable) audio-only RTSP dashboard with real waveforms, live listening, truthful channel states and reconnect with backoff
* Crash-safe hourly MP3 recording, self-healing index, synchronised timeline, Range playback, clip export, retention and disk guard
* Local transcription (faster-whisper + Silero VAD) with FTS search and TXT/JSON/CSV export
* YAMNet acoustic event detection with conservative thresholds, cooldowns and a review workflow
* Ollama summaries with injection hardening and verified citations
* Telegram and signed webhooks, alert rules and quiet hours
* RBAC, CSRF, rate limiting, audit log, encrypted secrets, strict CSP and systemd sandboxing
* Responsive PWA UI, keyboard shortcuts and demo mode
